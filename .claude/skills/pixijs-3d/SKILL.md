Read PixiJS 3D's own skill, in [node_modules/@pixi/3d/skills/pixijs-3d/SKILL.md](../../../node_modules/@pixi/3d/skills/pixijs-3d/SKILL.md), and its `references/` folder beside it. It's the copy that ships with the installed version, so it matches the API this repo uses.

Its examples drive features from Pixi's shared ticker (`autoUpdate`, `app.ticker`, `OrbitCamera`). In this repo, a view never moves anything on the shared ticker. Follow the mvt-view skill's 3D section ([packages/sites/docs/ai-agents/skill-mvt-view.md](../../../packages/sites/docs/ai-agents/skill-mvt-view.md#views-in-3d)) and `@mvtjs/pixi-3d`'s [README](../../../packages/libraries/pixi-3d/README.md). Where they differ from PixiJS 3D's skill, they take precedence.
