Breaking: `watch` has changed, and has two new companions, `createReaction` and `createComputed`. `memoiseLast` is gone. A reaction is a function you call on every step, which runs `react` when what it watches changes in a way that `when` accepts: `createReaction({ watch: bindings.phase, when: 'dying', react: () => sfx.play(EXPLODE) })`. The conditions are `increased`, `decreased` and `changedFrom(value)`, all exported. A computed value works out its value on its first read, and again only when what it watches changes. It's a getter, so it goes straight into a JSX prop: `createComputed({ watch: bindings.score, compute: String })`. `watch` now takes one getter, a record or an array. Its reading gives `current` where it gave `value`, `previous` equal to `current` when nothing changed, `changedTo(value)` and `changedFrom(value)`, and, for a record or an array, `anyChanged`. The first poll is now a starting point, not a change: nothing reacts because it was made, so a view draws its first state itself, and drops any poll it made at construction to skip that first change. A getter must return a primitive, and one that returns an object throws. A reading kept past the next poll throws in development. To move from `memoiseLast`, turn `text={() => scoreText(bindings.score())}` into `createComputed({ watch: bindings.score, compute: ... })` and `text={scoreText}`. See "Watching for Changes" in `src/watch-api/README.md`.
