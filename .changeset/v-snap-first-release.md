The first release of v-snap: fast, consistent visual snapshot tests for views drawn with Pixi, three.js, any canvas, or HTML, as Vitest projects. A test is one `canvasTest` or `htmlTest` declaration, whose pose returns the view, and its image is compared with a reference image committed beside the test. The images are the same on Windows, Linux and macOS, with no Docker.
