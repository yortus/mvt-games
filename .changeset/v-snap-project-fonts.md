Canvas text can be drawn in your project's own fonts. Register their files with the new `fonts` option, by family name, such as `vsnap({ fonts: { MyGameFont: 'assets/fonts/my-game-font.woff' } })`, and text that asks for a registered family is drawn in it. v-snap lays it out and draws it as it does its own fonts, so images still match on every machine, and text that doesn't fit in your font doesn't fit in the image either. A family takes one file, a list of files for its faces, or faces with their `weight` and `style`, which are otherwise read from each file. A face is picked for each weight and style as CSS picks one. A character that your font lacks falls back to the font list's later registered families, then to v-snap's own font. A font list that names a registered family doesn't need a generic family at the end. Registering `sans-serif` or `monospace` replaces v-snap's own font for that family, and for the system fonts drawn in it. Bold isn't faked for a family with no bold face. v-snap checks each file as the config loads, and the page loads the fonts before any of your code runs. A project that registers no fonts draws exactly as before, so your references stay as they are.
